🔁 For Loop Examples

| File | Logic |
| :--- | :--- |
| 1_forloop.js | Print "Hello World" multiple times |
| 2_horizontal.js | Print 1 to 5 in one line (horizontal) using sequence |
| 3_multiply.js | Multiplication logic - vertical & horizontal print |
| 4_reverse.js | Reverse loop 5 to 1 using decrement |
| 5_factorial.js | Calculate factorial of a number |
| 6_sum.js | Sum of numbers from 1 to N |
| 7_break.js | break statement demo - loop stops when condition matches |
| 8_continue.js | continue statement - skip particular value (3 is skipped) |
| 9_continue_count.js | Test final value of counter with continue |
| 10_continue_final.js | Check final answer by changing continue logic |

| File | Logic |
